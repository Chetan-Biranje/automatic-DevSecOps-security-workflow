# Contributing

Propose focused improvements through GitHub issues and pull requests. Report vulnerabilities privately using the repository security policy or an agreed private channel.

- Create a branch for each change and follow existing project conventions.
- Update documentation and run applicable tests and lint checks.
- Describe validation results and known limitations in the pull request.
- Use synthetic fixtures and authorized environments. Never commit secrets or private data.
- Respect existing licensing and third-party attribution.

Review and acceptance are on a best-effort basis.
